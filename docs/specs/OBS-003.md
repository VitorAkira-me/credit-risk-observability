## Objetivo
Quem ler o README entende cada número do painel sem perguntar a ninguém, e consegue decidir
"retreinar ou não" sozinho. Atende ao requisito "métricas documentadas" da Etapa 3.

## Conceito por trás (didático)
Um painel sem legenda é um painel de avião para quem nunca pilotou: tudo pisca e ninguém sabe o que
importa. A tabela liga cada número a uma das três perguntas do monitoramento (rodou? rodou bem? o
modelo ainda é confiável?) e diz a partir de quando ele vira alerta.

## Escopo
- Dentro: tabela no README (métrica, o que mede, por que importa, limiar, onde ver), prints de um run
  saudável e de um com alerta, guia de decisão "retreinar ou não".
- Fora: limiar calibrado para latência (sem dado histórico suficiente; fica como referência).

## Critérios de aceite (verificáveis)
- [x] Tabela com as 5 colunas do card e todas as métricas que o pipeline grava no MLflow.
- [x] Prints da UI do MLflow: semana 1 (todos os alertas `false`) e semana 4 (todos `true`).
- [x] Limiares iguais aos de `reports/monitoring/alert_thresholds.json`.
