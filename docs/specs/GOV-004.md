# GOV-004 · Análise causal da degradação e plano de ação

- Etapa: 4
- Status: concluída (código e texto do Claude no modo prazo; revisão do Akira pendente)
- Data: 08/11/2026
- Jira: [PMF4-25](https://akiravkax.atlassian.net/browse/PMF4-25)

## Objetivo
Explicar por que o modelo piorou, separando causa de correlação, ligando cada elo da cadeia a uma
evidência do projeto, e dizer o que fazer quando cada alerta dispara.

## Conceito por trás (didático)
Duas coisas que sobem juntas não provam que uma causa a outra: elas podem ter uma causa comum. Na
semana 4, o PSI de `LIMIT_BAL` e a queda de AUC subiram juntos porque aplicamos os dois drifts ao
mesmo tempo. Para separar, **intervém-se**: muda-se uma coisa de cada vez, em doses, e mede-se o
efeito. Se o efeito acompanha a dose de uma e ignora a outra, a causa está isolada. Analogia: para
saber se é o café ou o açúcar que tira o sono, toma-se cada um sozinho, em quantidades diferentes.

## Critérios de aceite (verificáveis)
- [x] Diagrama causal no README (mermaid).
- [x] Cada elo ligado a uma evidência (relatórios do DRIFT-002, painel do OBS-002, dose-resposta).
- [x] Experimento de intervenção: 5 doses de cada drift, aplicado sozinho.
- [x] Impacto no negócio em números: calote aprovado, bom cliente negado, exposição.
- [x] Plano de ação com gatilho, ação e critério para encerrar (investigar, retreinar, rollback,
      revisão humana).
- [x] Testes: contagens feitas à mão; data drift não mexe no alvo; concept drift sobe o default.

## Resultado
- Previsão do Claude: AUC parada com data drift, queda gradual com concept drift. **Acertou.**
- Data drift: AUC 0,7149 a 0,7144 com a dose cheia (sem efeito).
- Concept drift: AUC 0,7149, 0,7007, 0,6876, 0,6763, 0,6647 (queda linear com a dose).
- Negócio, concept drift cheio: calotes aprovados 716 para 1.114 (+56%); exposição NT$ 138 mi para
  NT$ 228 mi (+65%).
- Limite reconhecido: o experimento funciona porque nós causamos o drift; em produção, a mesma
  pergunta se responde com rótulos recentes, análise por segmento e retreino em janela nova.
